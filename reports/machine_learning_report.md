# Machine Learning Report

## Objective

Predict customer payment values using Machine Learning.

## Models Used

- Linear Regression
- Random Forest Regressor

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Best Model

Random Forest Regressor

## Key Findings

- Product price was the most influential feature.
- Freight value also significantly affected payment values.
- Random Forest achieved better predictive performance than Linear Regression.

## Business Recommendations

- Optimize product pricing strategy.
- Reduce freight costs where possible.
- Use the model for revenue forecasting and business planning.
